How to read this. Every 120–277V configuration that a state DOT list prints, with this exact model number, as Phase 2 compliant (US final assembly and more than 55% domestic component cost, for projects obligated on or after Oct 1, 2026), at any color temperature. TxDOT's Compliant v5, Alabama's Y2 code and Caltrans's "55% or higher cost and final assembly both in US" all mean Phase 2. The CCT column shows the color temperature the listing prints.
Phase 2 · 55% DOT says US final assembly and more than 55% domestic cost (projects obligated on/after Oct 1, 2026). Only these listings are shown.
Removed 2026-11-09: 37 listings that are not Phase 2 (final assembly only, "eligible" or "BAA" with no phase, TxDOT Compliant v4, or project-level certification). They are kept in data/fixtures_removed.json.
Every catalog number is copied from the state DOT list as printed; nothing is substituted or inferred. Only listings that print a 120–277V code (MVOLT, MV, UNV, U, 0, or "120-277 VAC") are included. TxDOT labels its rows 120/240V. Listings with a placeholder voltage, or a voltage code that could not be confirmed as 120–277V, are left out.
